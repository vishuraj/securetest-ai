# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability reporting:
*Security → Report a vulnerability* on https://github.com/vishuraj/securetest-ai.

Include the affected version, configuration, reproduction steps and impact. You will get an acknowledgement
within 5 working days. Fixes are released as new versions and announced in a GitHub security advisory.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Scope notes

The sample application deliberately contains insecure code, a fake AWS example key and insecure manifests so the
scanners have something to find. Those are not vulnerabilities in SecureTest.
